# Real Estate Listing API

Backend REST API for a real estate listing platform built with Node.js, Express, and MongoDB.
The system handles authentication, users, properties, and booking workflows.

## Tech Stack

- Node.js
- Express.js
- TypeScript
- MongoDB + Mongoose
- JWT Authentication
- Docker

## Project Structure

```
src/
├── controllers/
├── services/
│ └── entities/
├── models/
├── routes/
├── middlewares/
├── utils/
├── config/
├── errors/
└── types/
```

## Running the Project

```

Install dependencies:
npm install

Run development server:
npm run dev

## API Documentation

API documentation will be provided via Postman.
```
